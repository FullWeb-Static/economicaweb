## 🛠️ Stack Tecnológico y Arquitectura
- **Frontend:** HTML5 semántico, CSS3 (Flexbox/Grid), JavaScript Vanilla (sin frameworks pesados).
- **Infraestructura:** Despliegue en **GitHub Pages** protegido y acelerado con **Cloudflare** (CDN, WAF, SSL).
- **Optimización IA & SEO:** Implementación de `JSON-LD` (Schema.org), archivos `llms.txt` para ChatGPT/Perplexity, y `security.txt` para reporte de vulnerabilidades.
