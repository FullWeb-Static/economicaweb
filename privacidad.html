POLÍTICA DE PRIVACIDAD Y PROTECCIÓN DE DATOS

Última actualización: Noviembre 2026

1. Responsable del Tratamiento

El responsable del tratamiento de los datos recolectados en este sitio web es e-WEB, bajo el dominio corporativo economicaweb.cl. Canal exclusivo para derechos ARCO: privacidad@economicaweb.cl.

2. Datos Recolectados y Finalidad

A través de nuestro formulario de "Solicitud de Estudio Landing Page", solicitamos exclusivamente datos técnicos para evaluar la viabilidad de tu infraestructura digital. Tu nombre y correo se usan únicamente para enviar la propuesta formal. No solicitamos RUT ni documentos financieros en esta etapa.

3. Cookies y Datos de Navegación

Este sitio web no utiliza cookies de seguimiento, marketing ni analítica de terceros. Toda la analítica de red y el procesamiento de IP se ejecutan estrictamente mediante la infraestructura de Cloudflare Tunnel para garantizar la seguridad del servidor y mitigar ataques cibernéticos.

4. Seguridad y Cifrado

Todo el flujo de datos viaja de forma cifrada bajo protocolo seguro HTTPS mediante el túnel seguro de Cloudflare, garantizando un aislamiento hermético para evitar interceptaciones.

5. Derechos del Usuario (ARCO)

Conforme a la legislación chilena (Ley N° 21.719), puedes ejercer tus derechos de Acceso, Rectificación, Cancelación y Oposición escribiendo a privacidad@economicaweb.cl.
